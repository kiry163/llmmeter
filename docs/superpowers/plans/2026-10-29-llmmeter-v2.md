# llmmeter v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 重写 llmmeter 为单二进制本地网关：SQLite 即唯一状态、全路径字节记账、秒级实时面板、WebUI 管理价格与上游。

**Architecture:** 单写协程串行落库，读走 WAL；配置与价格用 `atomic.Pointer` 快照热替换；实时指标在内存环形缓冲中聚合并通过 SSE 广播；React SPA 构建产物经 `go:embed` 内嵌。

**Tech Stack:** Go 1.27.1、modernc.org/sqlite、golang.org/x/crypto（argon2）、React 19、Vite、TypeScript、Tailwind CSS 4、ECharts、TanStack Query、Vitest。

**Spec:** `docs/superpowers/specs/2026-10-29-llmmeter-v2-design.md`

## Global Constraints

- 模块路径 `github.com/kiry163/llmmeter`；Go 版本以现有 `go.mod`（1.27.1）为准。
- 删除 `config.yaml` 加载链路：不引入 YAML 依赖，`sample.config.yaml` 删除。
- 唯一持久状态是一个 SQLite 文件；无外部数据库、无 Node 运行时。
- DB 中时间戳为 RFC3339 UTC 毫秒；`local_day`/`minute_of_day` 写入时按快照时区计算。
- 金额一律整数纳美元（`cost_nano_usd`），展示时转 USD。
- 未拿到 usage 绝不估算；`priced=0` 只用于「解析出 usage 但模型未配置价格」。
- 密钥只回掩码；日志不得包含密钥、请求体、响应体。
- 中文 UI 文案；API JSON 使用 camelCase；错误体 `{"error":{"code","message","fields"}}`。
- 每个任务结束前跑该包测试；Task 13 起 `go build ./...` 与 `go test ./...` 必须全绿。
- 本计划是整仓重写：Task 1 删除旧实现，Task 1–12 只保证各自包测试通过，Task 13 恢复全仓构建。

```go
package store

import (
	"database/sql"
	"fmt"

	_ "modernc.org/sqlite"
)

func OpenDB(path string) (*sql.DB, error) {
	dsn := path + "?_pragma=journal_mode(WAL)&_pragma=synchronous(NORMAL)" +
		"&_pragma=busy_timeout(5000)&_pragma=foreign_keys(ON)"
	db, err := sql.Open("sqlite", dsn)
	if err != nil {
		return nil, fmt.Errorf("open sqlite: %w", err)
	}
	db.SetMaxOpenConns(8)
	db.SetMaxIdleConns(8)
	if _, err := db.Exec(Schema); err != nil {
		db.Close()
		return nil, fmt.Errorf("apply schema: %w", err)
	}
	if _, err := db.Exec(fmt.Sprintf("PRAGMA user_version = %d", UserVersion)); err != nil {
		db.Close()
		return nil, fmt.Errorf("set user_version: %w", err)
	}
	return db, nil
}
```

```go
package usage

import (
	"encoding/json"
)

type Usage struct {
	PromptTokens     int64
	CompletionTokens int64
	CacheReadTokens  int64
	CacheWriteTokens int64
	ReasoningTokens  int64
	TotalTokens      int64
}

const ( /* 见 Interfaces 的六个状态常量 */ )

type chatPayload struct {
	PromptTokens            int64  `json:"prompt_tokens"`
	CompletionTokens        int64  `json:"completion_tokens"`
	TotalTokens             int64  `json:"total_tokens"`
	PromptCacheHitTokens    *int64 `json:"prompt_cache_hit_tokens"`
	PromptTokensDetails     struct {
		CachedTokens int64 `json:"cached_tokens"`
	} `json:"prompt_tokens_details"`
	CompletionTokensDetails struct {
		ReasoningTokens int64 `json:"reasoning_tokens"`
	} `json:"completion_tokens_details"`
}

func ParseChatUsage(raw json.RawMessage) (Usage, bool) {
	if len(raw) == 0 || string(raw) == "null" {
		return Usage{}, false
	}
	var p chatPayload
	if err := json.Unmarshal(raw, &p); err != nil {
		return Usage{}, false
	}
	if p.PromptTokens == 0 && p.CompletionTokens == 0 && p.TotalTokens == 0 {
		return Usage{}, false
	}
	cache := p.PromptTokensDetails.CachedTokens
	if p.PromptCacheHitTokens != nil {
		cache = *p.PromptCacheHitTokens
	}
	total := p.TotalTokens
	if total == 0 {
		total = p.PromptTokens + p.CompletionTokens
	}
	return Usage{
		PromptTokens: p.PromptTokens, CompletionTokens: p.CompletionTokens,
		CacheReadTokens: cache, ReasoningTokens: p.CompletionTokensDetails.ReasoningTokens,
		TotalTokens: total,
	}, true
}

type responsesPayload struct {
	InputTokens        int64 `json:"input_tokens"`
	OutputTokens       int64 `json:"output_tokens"`
	TotalTokens        int64 `json:"total_tokens"`
	InputTokensDetails struct {
		CachedTokens int64 `json:"cached_tokens"`
	} `json:"input_tokens_details"`
	OutputTokensDetails struct {
		ReasoningTokens int64 `json:"reasoning_tokens"`
	} `json:"output_tokens_details"`
}

func ParseResponsesUsage(raw json.RawMessage) (Usage, bool) {
	if len(raw) == 0 || string(raw) == "null" {
		return Usage{}, false
	}
	var p responsesPayload
	if err := json.Unmarshal(raw, &p); err != nil {
		return Usage{}, false
	}
	if p.InputTokens == 0 && p.OutputTokens == 0 {
		return Usage{}, false
	}
	total := p.TotalTokens
	if total == 0 {
		total = p.InputTokens + p.OutputTokens
	}
	return Usage{
		PromptTokens: p.InputTokens, CompletionTokens: p.OutputTokens,
		CacheReadTokens: p.InputTokensDetails.CachedTokens,
		ReasoningTokens: p.OutputTokensDetails.ReasoningTokens,
		TotalTokens: total,
	}, true
}
```

- [ ] **Step 4: 实现**

- `MaskBit(wd) = 1 << ((int(wd)+6)%7)`（周一 bit0，周日 bit6）。
- `NewTable` 编译每个模型：按 `Windows` 顺序保存；`Quote` 先在 `loc` 下取 `minuteOfDay = hour*60+minute`（本地墙钟；DST 回拨导致的重复墙钟时间都匹配），逐窗口匹配：
  - `end > start`：`mask&currentBit != 0 && start <= m < end`
  - `end < start`：`(mask&currentBit != 0 && m >= start) || (mask&prevBit != 0 && m < end)`
- 合并费率：窗口字段非 nil 覆盖 base；`Reasoning` 为 nil 时用合并后的 Output。
- 成本：`round((p-cr)*input + cr*cacheRead + cw*cacheWrite + (c-reason)*output + reason*reasoning) * 1000`，先按 token×rate 求和，再乘 1000 并 `math.Round`；任何分量为负按 0。
- `RatesJSON`：`json.Marshal(struct{Model,Window,InputPerMTok,...})`，保留 6 位小数。
- `Quote.Priced=false` 时 `RatesJSON=""`、`WindowLabel="base"`。
